# Visit Locals Alpha — Asset Structure

All website media assets are centralized under `/assets/`.

```text
assets/
└── images/
    ├── branding/
    │   ├── visit-locals-logo.png
    │   └── favicon.png
    ├── experience/
    └── insights/
```

HTML pages remain outside `/assets/` because they are website routes/pages.
Images and other reusable media belong inside `/assets/`.

The supplied Visit Locals circular emblem is used as the website branding mark and favicon.
